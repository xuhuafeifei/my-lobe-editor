# Markdown ↔ 颜色文本 双向 — 设计契约

> **状态**：已同意并发布（2026-08-13，`1.0.0-fork.20`）— Phase1 导出 + Phase2 导入均已实现

> 语法：`<span style="color: …; background-color: …">…</span>`\
> 配对：HTML 开闭标签**只比较标签名**（如 `span`）

## 方案摘要

### Phase 1：导出（已完成）

Common text writer 读 `getStyle()`，包 span。

### Phase 2：导入（已完成）

1. `parse.ts`：`getHtmlTagName` — 配对只比 tag name
2. `mdReader`：带合法 color/background-color 的 span → 写入子 text 的 `style`
3. 配对失败 → 开 / 中 / 闭化为纯文本

## 变更触达

| 文件                                                 | 改动说明                |
| ---------------------------------------------------- | ----------------------- |
| `src/plugins/markdown/data-source/markdown/parse.ts` | `getHtmlTagName` + 配对 |
| `src/plugins/common/utils/textStyle.ts`              | 导出 / 导入 style 工具  |
| `src/plugins/common/plugin/index.ts`                 | text writer 包 span     |
| `src/plugins/common/plugin/mdReader.ts`              | span → style            |

## 风险与回滚

| 风险                     | 缓解                             |
| ------------------------ | -------------------------------- |
| style 注入               | 白名单属性 + 值校验              |
| formatMarkdown 破坏 span | 单测锁住；remark 已验证保留 span |

## 测试要点

- 仅 color / 仅 background / 两者
- 色 + bold
